## Parte 1: Análisis comparativo

| Característica/Aspecto          | Modelos Clásicos (Predictivos) | Modelos Evolutivos o Incrementales | Metodologías Ágiles (Adaptativas) |
|---------------------------------|--------------------------------|------------------------------------|-----------------------------------|
| **Definición Principal**         | Modelo secuencial y lineal del ciclo de vida del software, planificado y predecible. | Desarrollo por incrementos, con versiones sucesivas y ajustes progresivos. | Entrega iterativa y adaptativa; cambios continuos según el feedback del cliente. |
| **Características Clave / Enfoque** | Fases lineales: análisis, diseño, implementación, pruebas y mantenimiento; documentación exhaustiva. | Iterativo: cada incremento añade funcionalidad; realimentación temprana del usuario. | Iteraciones cortas , entrega frecuente, colaboración continua con el cliente y el equipo. |
| **Ventajas (Pros)**             | Claridad en planificación y control, además de útil con requisitos estables. | Permite adaptarse a cambios, reduce riesgos, entrega funcional temprana. | Alta flexibilidad,. rápida respuesta al cambio. |
| **Desventajas (Contras)**       | Poco flexible ante cambios, costoso si se detectan fallos tarde. | Requiere coordinación; planificación menos rígida, posibles costes adicionales. | Documentación limitada, requiere disciplina del equipo, planificación menos predecible. |
| **Aportación en la Actualidad** | Base de métodos estructurados, útil en proyectos críticos o regulados. | Base de enfoques iterativos y prototipos, soporte de metodologías híbridas. | Dominante en la industria, base de Scrum, clave en entornos cambiantes. |

## Parte 2: Reflexión sobre detección y corrección de fallos

**Modelos Clásicos (Cascada con Realimentación):**  
- Permiten volver a fases anteriores para corregir fallos.  
- Cambios tardíos y costosos, requiere documentación detallada.

**Modelos Evolutivos/Incrementales:**  
- Cada incremento permite refinar el sistema.  
- Realimentación temprana del usuario ayuda a corregir errores y ajustar requisistos.

**Metodologías Ágiles:**  
- Iteraciones cortas y entrega continua facilitan correcciones inmediatas.  
- XP y revisiones continuas permiten mejoras progresivas y adaptación constante.

**Fase de Mantenimiento:**  
- Correctivo:
Corrige defectos detectados tras la entrega.  
- Evolutivo/Adaptativo:
Permite adaptar el software a nuevos requisitos o cambios del entorno.  
- En modelos clásicos ocurre tras la entrega.
