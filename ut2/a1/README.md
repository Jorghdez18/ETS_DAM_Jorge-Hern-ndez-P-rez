# Clasificación, paradigmas y sistemas de tipado de los principales lenguajes de programación

| **Lenguaje** | **Clasificación del lenguaje** | **Paradigma(s)** | **Sistema de tipado** |
|---------------|--------------------------------|------------------|-----------------------|
| **1.Python** | Lenguaje de alto nivel, interpretado. Pertenece a la tercera generación de lenguajers. Su sintaxis es sencilla y está enfocada en la productividad y claridad. | Multiparadigma: soporta programación imperativa, orientada a objetos. Se usa en ciencia de datos, IA y desarrollo web. | Tipado dinámico y fuerte: los tipos se determinan en tiempo de ejecución, pero no se permiten conversiones implícitas peligrosas. |
| **2.C** | Lenguaje de medio nivel, compilado. Pertenece a la tercera generación, combina acceso directo al hardware con abstracción. | Principalmente imperativo y estructurado. Base de muchos otros lenguajes modernos. | Tipado estático y débil: los tipos se declaran y verifican en compilación, pero admite conversiones implícitas entre todos los tipos. |
| **3.C++** | Lenguaje de medio nivel, compilado. Derivado de C, añade abstracción orientada a objetos. | Multiparadigma: imperativo, orientado a objetos y genérico. | Tipado estático y fuert: requiere definición de tipos, pero permite plantillas genéricas con seguridad. |
| **4.Java** | Lenguaje de alto nivel, compilado. Portátil y seguro. | Orientado a objetos, con soporte para programación funcional desde Java 8. | Tipado estático y fuerte: los tipos se comprueban en compilación y el sistema evita errores mientras se ejecuta. |
| **5.C#** | Lenguaje de alto nivel, compilado (Common Language Runtime). Inspirado en C++ y Java. | Orientado a objetos y funcional. Ampliamente usado en entornos .NET | Tipado estático y fuerte con inferencia opcional, combinando la seguridad con flexibilidad. |
| **6.JavaScript** | Lenguaje de alto nivel. Diseñado para la web. | Multiparadigma: imperativo, orientado a objetos y funcional. | Tipado dinámico y débil: permite conversiones automáticas entre tipos, lo que puede generar errores sutiles. |
| **7.Visual Basic** | Lenguaje de alto nivel, interpretado y compilado. Diseñado por Microsoft para desarrollo rápido. | Orientado a objetos con enfoque en la programación de eventos. | Tipado estático y fuerte, aunque admite modos dinámicos. |
| **8.Delphi (Object Pascal)** | Lenguaje de alto nivel, compilado. Heredero de Pascal, centrado en el desarrollo visual. | Orientado a objetos y estructurado, con soporte para programación visual de interfaces. | Tipado estático y fuerte, típico de la familia Pascal, con comprobación rigurosa de tipos. |
| **9.Perl** | Lenguaje de alto nivel, interpretado. Diseñado para manipulación de texto y scripting. | Multiparadigma: imperativo, orientado a objetos. | Tipado dinámico y débil, lo que permite gran flexibilidad en la gestión de tipos. |
| **10.SQL** | Pertenece a la cuarta generación, orientado a bases de datos. | Declarativo: se especifica qué datos se quieren, no cómo obtenerlos. | No posee tipado tradicional: los tipos se definen por columnas y se validan en la base de datos. |
| **11.Go** | Lenguaje de alto nivel, compilado, desarrollado por Google. Combina eficiencia con simplicidad. | Imperativo, concurrente y estructurado, con soporte nativo. | Tipado estático y fuerte con inferencia limitada, asegurando rendimiento y fiabilidad. |
| **12.R** | Lenguaje de alto nivel, interpretado. Creado para análisis estadístico. | Funcional y vectorial, con rasgos imperativos. | Tipado dinámico y fuerte, los tipos son flexibles pero se respetan en ejecución. |
| **13.Fortran** | Lenguaje de alto nivel, compilado. Uno de los más antiguos, orientado al cálculo numérico. | Imperativo y estructurado, con soporte para programación modular en versiones modernas. | Tipado estático y fuert, enfocado en precisión numérica. |
| **14.Rust** | Lenguaje de alto nivel, compilado. Diseñado para rendimiento. | Multiparadigma: imperativo, funcional y orientado a objetos limitado. | Tipado estático y fuerte, con control estricto de memoria y propiedad de datos. |
| **15.Assembly language** | Pertenece a la segunda generación, es un lenguaje de bajo nivel , casi equivalente al código máquina; compilado mediante ensamblador y muy cercano al hardware. | Imperativo puro y estructural, orientado al control detallado del hardware y ejecución directa de instrucciones. | Tipado ninguno o mínimo: las instrucciones manipulan registros sin un sistema de tipos explícitos propio del lenguaje de alto nivel. |
| **16.Matlab** | Lenguaje de alto nivel, interpretado. Enfocado en cálulo numérico, matrices y simulaciones. | Imperativo y funcional, especializado en programación científica. | Tipado dinámico y  furte, las variables cambian tipo en tiempo de ejecución con control estricto. |
| **17.PHP** | Lenguaje de alto nivel, interpretado, centrado en el desarollo web. | Multiparadigma: imperativo, orientado a objetos y funcional. | Tipado débil y dinámico, aunque PHP permite tipado opcional estático. |
| **18.Ada** | Lenguaje de alto nivel, compilado. | Imperativo y orientado a objetos, con énfasis en fiabilidad y concurrencia. | Tipado estático y fuerte, con comprobación rigurosa para prevenir errores en sistemas críticos. |
| **19.Scratch** | Lenguaje visual, de alto nivel, interpretado. Pensado para educación y el aprendizaje. | Basado en eventos y orientado a objetos gráficos. | Tipado dinámico, los tipos se manejan de forma implícita por el entorno. |
| **20.Kotlin** | Lenguaje de alto nivel, compilado. Diseñado para interoperar con Java. | Orientado a objetos y funcional, con sintaxis moderna y segura. | Tipado estático y fuerte, con inferencia avanzada y control de nulabilidad. |
