## Reflexión final

- **¿Qué partes del código no estaban cubiertas?**

  Inicialmente, no estaban cubiertos los casos excepcionales: cuando la lista de notas está vacía y cuando alguna nota está fuera del rango permitido (menor que 0 o mayor que 10).

- **¿Qué tests has añadido?**

  Se añadieron tests para verificar que se lance la excepción cuando:
  - Lista vacía.
  - Nota fuera de rango (menos que 0 y mas de 10).

- **¿Qué cobertura final has obtenido?**

  Tras agregar estos tests, la cobertura del código aumentó hasta llegar al 87%.
